# DropShelf v2.0.0

A major productivity update for macOS.

## New Features

- Capture Studio
- Custom Actions and reusable workflows
- Intelligent Shelf Names
- Folder Monitoring
- Favourite file locations
- Customizable keyboard shortcuts
- Configurable storage location

## Improvements

- Redesigned native macOS settings
- Improved image and document tools
- Better shelf interactions
- Automatic light and dark appearance
- Updated automatic update configuration
- Stability improvements

## Compatibility

- Apple Silicon Macs
- macOS 13 or later
- Some features require newer macOS versions

## Installation

Download DropShelf.dmg and move DropShelf to Applications.

This build is ad-hoc signed and not Apple-notarized.
Existing users may require a one-time manual update.
